# Community templates

User-submitted FigureStyle templates, shared here for anyone to download and import.

## Using one

Download the `.json` (or `.cxc`) file, then in FigureStyle's **Templates I/O** tab:
- `.json` → **Import...**
- `.cxc` → **Run .cxc...**

## Submitting one

Export your template (**Templates I/O → Export...** for `.json`, or **Save as .cxc...**) and send
it one of two ways:

- Open a [GitHub Issue](https://github.com/LUKASinScience/ChimeraX-FigureStyle/issues) or pull
  request with the file attached, or
- Email it to **lukasinscience@gmail.com**

Include a short description of what it's for. Accepted submissions get added to this folder.
